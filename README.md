# Проект

**Автор:** Савонов Алексей
**Дисциплина:** Жизненный цикл разработки программного обеспечения

## Описание проекта

Учебный проект в рамках дисциплины «Жизненный цикл разработки программного обеспечения».

## Структура репозитория

- `docs/` — проектная документация
  - `docs/srs.md` — спецификация требований (SRS)
  - `docs/sdd.md` — описание дизайна (SDD)
  - `docs/requirements/` — отдельные требования
  - `docs/design/` — отдельные представления дизайна
  - `docs/decisions/` — архитектурные решения (ADR)
- `src/` — исходный код приложения
- `tests/` — тесты
- `srs/`, `sdd/`, `adr/` — исходные шаблоны (из репозитория курса)
