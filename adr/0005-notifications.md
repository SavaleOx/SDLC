# ADR-0005: Уведомления через системный трей с деградацией без трея

* **Статус:** Принято
* **Дата:** 2026-11-01
* **Автор:** Савонов А.И.
* **Связанные требования:** `REQ-INT-006`, `REQ-AVAIL-002`, `REQ-PORT-002`, `REQ-MAINT-003`

## Контекст и постановка задачи
Пользователь должен получать своевременные напоминания о привычках, не держа главное окно на переднем плане. При этом не все среды рабочего стола поддерживают системный трей, а формат всплывающих уведомлений различается между ОС. Необходимо выбрать способ уведомлений, который не блокирует основной сценарий работы с привычками и не приводит к аварийному завершению при отсутствии трея.

## Рассмотренные варианты
1. **Уведомления через `QSystemTrayIcon` (значок приложения и всплывающие сообщения) с деградацией при отсутствии трея**
2. **Собственные всплывающие окна поверх главного окна**
3. **Отказ от уведомлений, только индикация внутри главного окна**

## Принятое решение
Выбран вариант **1: уведомления через `QSystemTrayIcon` с контролируемой деградацией при отсутствии системного трея**.

### Обоснование
* **Штатное средство Qt (`REQ-INT-006`):** `QSystemTrayIcon` отображает значок приложения в области уведомлений и показывает всплывающие сообщения о событиях привычек; взаимодействие со значком не приводит к потере данных.
* **Устойчивость (`REQ-AVAIL-002`):** при отсутствии поддержки трея в среде рабочего стола приложение продолжает работать, основные функции доступны, невозможность показа уведомления обрабатывается без критической ошибки.
* **Кроссплатформенность (`REQ-PORT-002`):** поведение уведомлений документируется для каждой заявленной ОС; различия между средами рабочего стола фиксируются.
* **Изоляция (`REQ-MAINT-003`):** логика уведомлений сосредоточена в `NotificationController` и не смешивается с хранением привычек и построением статистики.

## Последствия
* **Положительные:** своевременные напоминания без удержания главного окна на переднем плане, единый компонент уведомлений, возможность проверять его отдельно от БД и графиков.
* **Отрицательные:** в средах без системного трея уведомления недоступны; формат и поведение всплывающих сообщений различаются между ОС и требуют документирования и отдельной проверки по каждой заявленной ОС.
